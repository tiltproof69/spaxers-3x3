## Supported versions

| Loader | Minecraft |
|---|---|
| **NeoForge** | 26.3 · 26.2 · 26.1.2 · 1.21.8 · 1.21.4 · 1.21.1 · 1.20.6 · 1.20.4 |
| **Fabric** | 26.3 · 26.1.2 · 1.21.8 · 1.20.1 (needs Fabric API) |

## The 3x3 family

Spaxers 3x3! works on its own and teams up with <a href="https://www.curseforge.com/minecraft/mc-mods/hammers-extension">Hammers 3x3!</a> · <a href="https://www.curseforge.com/minecraft/mc-mods/double-axes-extension">Double Axes 3x3!</a> · <a href="https://www.curseforge.com/minecraft/mc-mods/spades-extension">Spades 3x3!</a>.
Found something that only happens with two of them installed? Report it here or on any of their trackers.

## Where to find the logs

| | |
|---|---|
| **Crash** | `.minecraft/crash-reports/` - the newest file |
| **Anything else** | `.minecraft/logs/latest.log` |

Using a launcher like CurseForge, Prism or Modrinth App? Open your instance folder and the files are in the same place.
Big logs are easiest to share through [mclo.gs](https://mclo.gs) - just paste the link.
